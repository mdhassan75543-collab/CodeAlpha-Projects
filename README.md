# 🖼️ Image Gallery

A responsive and interactive **Image Gallery** built using **HTML, CSS, and JavaScript** as part of my CodeAlpha Frontend Development Internship.

## ✨ Features

- 📸 Responsive image gallery
- 🔍 Lightbox image preview
- ⬅️ Previous image navigation
- ➡️ Next image navigation
- 🎨 Hover effects
- ✨ Smooth transitions
- 🔎 Image category filters
- 📱 Mobile-friendly responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
